## 四面近景与动作证据

独立预览：`http://127.0.0.1:5288/src/chapter2/assets/preview.html`。命令为在本副本执行 `npm run dev -- --port 5288 --strictPort`。预览不挂main、不读写存档、不注册公共进度，不改变第一关。渲染采用main.js的基础半球光、太阳光、环境光、RoomEnvironment、ACES曝光1.08、48°相机，以及yaw .22/pitch .49、跟随距离10；另提供近景距离4。没有D区世界、AO、水面与实际遮挡，不能把这个台架当D区实景验收。

8个对象实际解码并留四面截图：08、17、28、21、23、蒸笼、货包、盘绳。五个候选人物各3段剪辑，33帧跨循环采样，用SkinnedMesh.getVertexPosition记录真实蒙皮顶点位移及原始坐标脚底范围；并验证SkeletonUtils.clone的骨骼对象独立，改变第一实例不改变第二实例。`browser-review.json`保留结果。它证明剪辑驱动蒙皮，不证明手与竿、绳接触正确，也不证明长袍全程无穿插。

人物模型本体与包装root/fit/朝向节点分开。现有人物源朝向约+X，外层yaw -π/2使正面约+Z；放入场景仍需按逐模型和锚点测量。带担/杆资产要按身体身高定标，不能按包含高举工具的全包围盒缩成矮人。计划尺寸为米制建议；从原始规范化空间到游戏尺度通过外层fit完成，禁止直接改已验收GLB。

## 分类与制作顺序

完整逐项清单在asset-plan.md/json，覆盖冻结契约18个资产ID，加10个本地美术/动作建议ID，合计28项。本地ID不增加公共物品、动作或锚点。每项含英文提示词及SHA256、分件、面/贴图预算、尺寸、原点朝向、预计费用、尝试上限和明确未产出的交付路径。

1. 01/02锁定外观/故事/参考近景后，先局部复用掌柜、脚夫、伙计，渔夫先试23/21局部改件；现有idle/walk优先保留，不重绑已可用骨架。
2. 简单竹竿、钓线、浮子、绳和支架用Three.js几何或Blender；两种鱼、碎物、铜扣、木牌、铃、盏、食物、箱笼、鱼篓也优先本地制作。非人形小件不套人形骨骼。渔夫只有在局部改件无法达到质量时才考虑单个AI新外观。
3. 钓鱼Cast/Wait/Lift和修缮Inspect/Align/Tighten/Test分别按阿青及脚夫实际骨架制作；Idle/Walk/拉纤绳/擦汗都不能替代这些专用动作。结绳工艺未核定前，只称游戏绑缚操作，不宣称复原宋代手艺。
4. 逐个完整播放，在D区真实光照/近景检查肤色、脚底、衣袍、袖/腕、手与物件、箱盖、绳端连续性、缺口/刻痕可见度，再进行实际设备性能比较。
