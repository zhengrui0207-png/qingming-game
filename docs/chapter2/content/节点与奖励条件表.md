# 节点、条件、动作与奖励表

所有 ID 与动作采用 P0 契约 1.0.0。条件用于展示与导向；服务仍须校验状态与原子结算。关闭、取消、失败不跳转成功节点，不发奖。`intent` 是内容的 UI 意图，不能当服务动作发送。

## 主线与报酬

两条路径共有：入区 → 接主线 → 借竿教学 → 钓得普通鱼并真实卖出一尾 → 修缮四步 → 领取一种报酬 → 门前交架 → 完成本关 → 确认结局。已先钓/先卖者读取保存进度，不重新要求刷鱼。

|事项|条件|效果|边界|
|---|---|---|---|
|现金报酬|修缮成功且未领取|16 文一次|与铜铃互斥；后续可用20文取得一次铜铃|
|铜铃报酬|修缮成功且未领取|铜铃唯一实例一次|不另给16文；不要求读完故事或换盏|
|木牌|接受取牌支线，在指定浅岸完成取物|归还确认后赠留、故事解锁|固定一次，不靠随机珍稀掉落|
|青釉盏|18文购买，或满足保护/任务条件后用铜铃换物|唯一实例、故事解锁|不要求走两条取得路径；现金购铃与铃换盏为可选|
|门前交接|三个前置目标完成|记录交架，再完成主线|交架后刷新可续办；结局不再发奖|
|故事阅读|首次取得物品|全文可读，按节段记录位置|读全文不推进主线；售出不抹去收藏历史|
