# 汴河入画 · 本地交付包

本目录是2026-09-17 音量、店铺配音、车辆人物朝向与驮牛更新后的静态生产产物，不含开发工具、生成服务或凭证。发布目标为魔搭 ranina0207/qingming 与阿里云 /qingming/。

## 启动

安装 Python 3，在本文件所在目录执行：

```sh
python3 -m http.server 5189 --bind 127.0.0.1
```

访问 http://127.0.0.1:5189/ 。不要双击 index.html。Ctrl+C 关闭服务。端口占用时更换端口，但新端口不会自动继承旧端口的浏览器存档。

如把该目录放在父目录下命名为 qingming，从父目录启动相同命令后访问 http://127.0.0.1:5189/qingming/ 。应保留 URL 尾部斜杠。

游戏资源随包提供，无需 Node、npm 或生成 API。必须保留整个 assets 目录。对话与书卷内嵌宋体子集（Noto Serif SC，OFL 许可见 assets/fonts/OFL.txt），缺字时回退系统字体；运行不下载网络字体。无外网时仍可通过本地 HTTP 游玩；风物志原文摘录随包提供，不外跳。没有 Service Worker，本地服务关闭后不能依赖缓存刷新。

存档是浏览器 localStorage，键为 qingming:hongqiao:save 及其 :backup、:corrupt。按协议、主机、端口隔离，同来源的不同路径共享；不具备云端或跨设备同步。保存失败时先重试，不要刷新。复制本文件夹不会复制浏览器存档。

release-manifest.json 记录文件 SHA-256、字节数和源码哈希。部署仅需标准静态服务，WASM MIME 为 application/wasm；不要将缺失资产回退成 HTML。保留上一完整版本用于回退。

此包仅完成本机开发验证；开场动画按要求跳过验收，移动端、其他浏览器、低配置设备与实际外网部署未验收。场景/人物较大，首次加载需要等待。行人采用范围受限的绕行与退让，密集处仍会等待，尚非完整城市生活模拟；衣袖及手持物未做逐网格碰撞。马匹采用 Tripo 模型和骨架，动作使用本地修正的 idle/walk。

人物远景保留骨骼动画，使用切换缓冲；虹桥拥挤镜头本机采样约 14 FPS，性能尚未验收。

本次背景音保留用户原 WAV，音量由 0.22 调为 0.07。胡饼配音对应王家蒸作 08 掌柜，阿成送食声在脚店门口触发。卖花姑娘靠近 4.5 米触发、离开 6 米停止。新牛保留 Tripo 网格、贴图和四足骨架，使用本地修正并烘焙的动作；独立驮货由 Blender 建模。
