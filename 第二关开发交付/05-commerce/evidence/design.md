# 铺前交易簿设计

目标：面对面交易时，把“持有／单价／数量／收入”“价格／精力上限后的恢复量”和欠账优先偿还讲清楚。

菜单采用右侧纸页，左侧保留角色与铺面；细账线承载数量，收据以朱砂落账印表示已保存。未确认报价不使用落账印。主按钮只在明确确认页使用朱砂色，默认聚焦“暂不成交”，降低误触。

色彩：墨绿 #24352F、米纸 #ECE7D6、青黛 #314F59、朱砂 #963D2C、苇色 #9C956D。题头为宋体，正文为系统中文无衬线；数字等宽对齐。全部样式限定在 c2-commerce 与 c2-commerce-hud，不覆盖全局按钮、风物志或旧入口。

页签按商铺能力分开。默认出售列表仅含本铺普通收购物；独一藏物在「藏物」页单独处理，解除后不会顺手售出。回购显示原笔数量、原价与原物说明，换物明确写一次限额和铜铃不能回购。

手机宽度采用底部纸页、可纵向滚动，不缩小正文挤交易数量。键盘焦点环、Tab循环、原生按钮和输入标签提供可操作性；不覆盖宿主全局按键管理。
